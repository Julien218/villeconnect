# Non-obvious setup and verification

- Base44 preview is Expo/Metro web on 3000 and tRPC API on 8000, from bind-mounted source. Never set `CI=1` on Metro: it disables live reload. Node 22 is needed for the current Expo toolchain; the repository CI's older Node version should be reviewed separately.
- `server` originally referenced uninstalled ts-node. Its dev command now uses `tsx watch`. Production remains `npm run build && npm start`.
- Production legacy schema/migrations 001-006 are NOT in this repository. `.base44/bootstrap.sql` is an inferred minimal DEV-ONLY schema, not a production migration. The setup service runs it and existing migrations 007, 010-014 against a separate local MySQL. Never apply it to Railway or claim production migration validation. No business records are seeded.
- MySQL has no published host port. App database URI under Compose environment intentionally targets local infrastructure; never place third-party secrets there. Managed secrets are loaded last from `/run/base44/app.env`. Resend is optional at boot but actual verification/reset email delivery needs a real key and verified sender.
- CORS uses the dynamically resolved preview origin; client calls API with Bearer tokens, not cross-site cookies. `TRUST_PROXY_HOPS` defaults to zero. Configure it only for verified trusted proxy paths; context must use Express `req.ip`, never the raw leftmost forwarding header.
- Legacy guest resolution must reject email/password accounts, privileged/inactive/merged users. Protected procedures recheck DB identity/state/roles so old device JWTs cannot survive account conversion. Keep the auth-security tests when changing these paths.
- Tests: `docker compose -f docker-compose.base44.yml exec -T api npm run validate`; frontend `exec -T web npx tsc --noEmit`; dependency checks `exec -T <api|web> npm audit --omit=dev`.
- September 2026 audit: API has zero reported advisories after compatible updates. Expo retains three moderate reports on a single decode-uri-component -> query-string -> expo-router chain. Do not blindly `npm audit fix --force`: it downgrades the router incompatibly; decode-uri-component 0.5 is ESM, so a global override also needs compatibility work. Sharp was patched to 0.35.4.
- `scripts/backup-project.sh` is MANUAL and LOCAL ONLY. Needs a clean Git tree, GPG public key with verified trust, private output directory outside repo. It bundles all locally known refs, dumps local DB, encrypts, and creates a checksum. It does not fetch, push, save runtime secrets, or back up production. Tested with a disposable key, a local clone, and an isolated MySQL restore of 26 tables. No retained or off-site backup was activated.
